#### Linux/Unix Deep Dive Schedule (Feb-Mar 2026)

**Week 1-2 (Feb 1-14): Linux Setup & Fundamentals**
- **Day 1-2:** Install Linux (dual-boot Ubuntu 22.04 or VM)
- **Day 3-4:** File system navigation (cd, ls, pwd, tree, find)
- **Day 5-6:** File operations (cp, mv, rm, mkdir, touch, cat, less, head, tail)
- **Day 7:** Package management (apt, dpkg, software installation)
- **Practice:** Navigate your cache/DRAM project directories, organize files using command line
- **Deliverable:** Can navigate entire file system without GUI

**Week 3-4 (Feb 15-28): Text Processing & Shell Basics**
- **Day 8-9:** Text editors (vim/nano basics, learn vim motions)
- **Day 10-11:** Text processing (grep, sed, awk, cut, sort, uniq)
- **Day 12-13:** I/O redirection (>, >>, <, |, tee)
- **Day 14:** Permissions (chmod, chown, umask)
- **Practice:** Edit Verilog files in vim, search log files with grep, process simulation outputs
- **Deliverable:** Comfortable editing code in vim, processing text data

**Week 5-6 (Mar 1-14): Shell Scripting & Automation**
- **Day 15-16:** Bash scripting basics (variables, conditionals, loops)
- **Day 17-18:** Functions, arrays, string manipulation
- **Day 19-20:** Script automation (cron jobs, at commands)
- **Day 21:** Error handling and debugging (set -e, set -x, trap)
- **Practice:** Write scripts to automate testbench runs, parse simulation results
- **Deliverable:** Automated build/test scripts for your projects

**Week 7-8 (Mar 15-31): Advanced Unix Skills**
- **Day 22-23:** Process management (ps, top, htop, kill, jobs, bg, fg)
- **Day 24-25:** System monitoring (df, du, free, vmstat, iostat)
- **Day 26-27:** Network tools (ssh, scp, rsync, wget, curl)
- **Day 28:** Git from command line (clone, add, commit, push, pull, branch, merge)
- **Practice:** SSH to remote machines, transfer files, monitor resource usage during simulations
- **Deliverable:** Can work entirely from remote terminal, manage git repos via CLI

**Daily Practice Routine (30 min/day):**
- Morning: Do 1 task entirely in terminal (no GUI)
- Evening: Read man pages for 2-3 commands you used that day
- Weekend: Build a small automation script
